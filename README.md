# MUHSIN — Creative Portfolio

A responsive Arabic/English portfolio for photography, video, Lightroom edits and AI artwork.

## Preview locally
Open `index.html` in a browser. No build step or package installation is required.

## Publish with GitHub Pages
1. Open the repository **Settings**.
2. Select **Pages** from the left sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then Save.
5. GitHub Pages will publish the site at:
   `https://prosw-coder.github.io/muhsin-creative-portfolio/`

## Personalize before launch
- Replace the sample Unsplash images in `index.html` with your own work.
- Update the email, Instagram and WhatsApp links in the contact section.
- Change the sample project titles and categories to your real portfolio entries.

## Important
This first version is a static portfolio. It includes responsive layouts, Arabic/English switching, category filters and an image lightbox. It does not yet include authenticated owner uploads or persistent video/image storage. Those require a secure storage/backend integration; never put secret keys in frontend files.
